# Kamay-Gabay — Official Website

> *Empowering Voices, Embracing Inclusion.*

Youth-led community organization website based in Barangay Tibungco, Davao City, Philippines.

---

## Tech Stack

- **Framework:** Vite 8 + React 19
- **Styling:** Tailwind CSS v4
- **Animation:** Motion (Framer Motion)
- **Routing:** React Router v7
- **Backend:** Supabase (Auth, PostgreSQL, Storage)
- **Icons:** Lucide React
- **Deployment:** Vercel
